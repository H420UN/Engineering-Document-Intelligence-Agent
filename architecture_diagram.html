Agent Execution Flow — Step by Step
1
User submits query — natural language engineering question via CLI or UI
2
LangGraph StateGraph starts — query wrapped as HumanMessage, injected into state
3
Agent node runs — GPT-4o receives system prompt + full message history, reasons about what tools to call
4
Tool calls emitted — LLM outputs structured JSON: tool name + arguments (no code runs inside LLM)
5
ToolNode executes — LangGraph intercepts tool_calls, runs Python functions, appends ToolMessages to state
6
Loop back to agent — GPT-4o reads tool results, reasons again, calls more tools or produces final answer
7
Report generated — final call to generate_structured_report compiles everything into a formal document
